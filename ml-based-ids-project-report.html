1. Executive Summary

This project delivers a complete, end-to-end Machine Learning–based Network Intrusion Detection System (IDS) as a single Python file (app.py). The system captures live network packets using Scapy, extracts 41 NSL-KDD-compatible features per connection, classifies traffic into five categories using a trained Random Forest model, persists alerts to SQLite, and visualises everything in a real-time Streamlit dashboard.

Single-file design: All six subsystems — preprocessing, training, inference, alert management, live capture, and the dashboard — are self-contained inside one app.py with no internal imports. Running the project requires only pip install -r requirements.txt.

6. Dataset — NSL-KDD

The NSL-KDD dataset is the standard benchmark for IDS research, derived from the KDD Cup 1999 dataset with redundant records removed.

Each record has 41 features: 9 basic (protocol, bytes, flags), 13 content-based (login attempts, shells), 9 time-based traffic stats, 10 host-based traffic stats.
